# LuxxitoSports

Sistema web para la reserva de canchas deportivas, gestión de pagos, validación de comprobantes, precios dinámicos, inventario de extras y reportes administrativos.

## Estructura del proyecto

- frontend/: interfaz web desarrollada con React, Vite y Tailwind CSS.
- backend/: API REST desarrollada con Django y Django REST Framework.
- docs/: documentación técnica del sistema.
- docker-compose.yml: configuración para levantar frontend, backend, PostgreSQL y Redis.
